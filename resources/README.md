# Resources

This folder contains image resources for the circuit simulator.

## Component Images

- `components/resistor.png` - Resistor symbol (zigzag pattern)
- `components/capacitor.png` - Capacitor symbol (parallel lines)
- `components/inductor.png` - Inductor symbol (coil loops)
- `components/voltage_source.png` - Voltage source symbol (circle with +/-)
- `components/ground.png` - Ground symbol (triangular with lines)

## Image Requirements

- Format: PNG with transparency
- Recommended size: 64x32 pixels for horizontal components
- Background: Transparent
- Color: Black lines on transparent background

## Usage

Images are loaded by the App class and used in the drawVisualComponent function to render components on the canvas.
